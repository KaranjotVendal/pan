# Decision records

Each file here records one decision about how pan is built: the context, the options that were
weighed, what was chosen and what follows from it. A record is numbered in the order it was
written and has a status: proposed (open for discussion), accepted (in force) or rejected (not
taken). Rejected records stay in the folder so the reasoning is not lost, and a later decision
that changes an earlier one is a new record that names the one it replaces. A change that breaks
a rule set by an accepted record comes with a new record in the same pull request.
